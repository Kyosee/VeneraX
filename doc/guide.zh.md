## AI 翻译

识别页面中的文字，将译文绘制到原图上，画面内容保留。

文字检测与识别在本机完成，识别出的文本发送至用户自行配置的 AI 服务翻译。应用不含任何账号或额度。

<!--anchor:translation-setup-->
### 配置

1. 设置 → AI 翻译。
2. 「LLM 服务商」→ 新增。选「谷歌翻译」即用它的免费接口，不需要账号和 Key，什么都不用填，保存即可用；缺点是每句话单独翻译，不同页之间的用词和人名可能不一致，效果不如 AI 模型。该接口非官方开放，可能被限流或随时失效，介意稳定性请用 AI 模型。
3. 想要更好的效果就选「AI 模型」：填写 API 地址和 API Key（部分本地服务可留空），点击「获取模型」选择模型。兼容 OpenAI 接口的服务均可。模型列表获取失败时可手动输入模型名。可添加多个服务商并随时切换。
4. 「测试翻译」→ 返回译文表示配置可用。
5. 「翻译模型」→ 下载。文字检测模型（约 5 MB）为必需；识别模型按漫画语言选择其一：

| 语言 | 体积 |
| --- | --- |
| 日文（含竖排） | 约 460 MB |
| 中文（简体 + 繁体） | 约 17 MB |
| 中文 / 拉丁字母（仅简体） | 约 11 MB |
| 英文 | 约 9 MB |
| 韩文 | 约 8 MB |

「源语言」保持「自动检测」时，检测模型加任一识别模型即可使用，应用会自行判定每部漫画的语言。

<!--anchor:translation-target-->
### 目标语言

「目标语言」内置简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、俄语、越南语。列表里没有的语言可以自己添加：

1. 设置 → AI 翻译 →「自定义语言」→「目标语言」右侧「+」。
2. 「语言名称」：AI 模型按这个名称翻译，建议用该语言自己的写法，如 `ไทย`、`Bahasa Indonesia`。
3. 「语言代码」：传给谷歌翻译和翻译脚本，如 `th`、`id`、`pt-BR`，按所用服务支持的代码填写。
4. 保存后，在「目标语言」里选中它即可。

- 已翻译的页面按语言代码保存，所以代码添加后不能修改，名称可以随时修改。
- 删除自定义语言不会删除已翻译的页面；之后添加同一代码，这些页面会重新显示。
- 内置语言不能删除或修改。自定义语言列表随备份在设备间同步。
- 源语言的扩展见下一节。
- 译文按从左到右排版，阿拉伯语、希伯来语等从右向左书写的语言可能显示不正确。

<!--anchor:translation-source-->
### 源语言与识别模型

内置源语言及其使用的识别模型：

| 源语言 | 识别模型 |
| --- | --- |
| 日文 | 日文模型（约 460 MB），竖排横排都能识别 |
| 简体中文 | 中文（简体 + 繁体）模型；未下载时使用中文 / 拉丁字母模型 |
| 繁体中文 | 中文（简体 + 繁体）模型（约 17 MB），必须下载 |
| 英文 | 英文模型 |
| 韩文 | 韩文模型 |

- 中文 / 拉丁字母模型（约 11 MB）只收录简体常用字，缺少约 3800 个繁体字，繁体漫画会识别出错字。中文（简体 + 繁体）模型收录约 1.8 万字，简繁都能识别，竖排中文也能识别；下载后简体中文也会改用它。
- 「自动检测」会区分简体和繁体，繁体漫画翻译成简体中文时会照常翻译。
- 繁体漫画建议在「源语言」中直接选「繁体中文」。竖排中文在「自动检测」下可能被日文模型当成日文识别，直接选择语言可避免这个问题。
- 在本次更新前打开过的繁体页面，可能已被记为「没有可翻译的文字」。在详情页长按「预翻译」→「重新翻译」后即可正常翻译。

**模型大小与识别效果**

模型越大，收录的字和见过的字体越多，识别越准；代价是下载更大、首次加载更慢、占用内存更多，手机上更容易发热。字典里没有的字一律会被识别成形近字，所以「字够不够」比模型大小更关键。以下是在电脑上用渲染出的繁体对白测得的字错误率，实际漫画的字体与网点会更难：

| 模型 | 结果 |
| --- | --- |
| 中文 / 拉丁字母（约 11 MB） | 繁体错字率约 17%，竖排无法识别 |
| 中文（简体 + 繁体）（约 17 MB） | 繁体、简体、竖排均无错字 |
| PP-OCRv6 small（约 21 MB） | 与上一项相当，速度略慢 |
| PP-OCRv6 tiny（约 4.5 MB） | 速度约快 3 倍，繁体错字率约 18% |

**添加其他源语言**

1. 设置 → AI 翻译 →「自定义语言」→「源语言」右侧「+」。
2. 填写语言名称和语言代码（如 `fr`、`ru`、`th`）。
3. 填写识别模型链接（.onnx）和字符字典链接（.txt），或点「填入已验证的模型」选择拉丁字母、西里尔字母、泰语之一。
4. 保存时会读取文件大小，确认后开始下载。体积超过 100 MB 会额外提示。

- 只支持 ONNX 格式的 PP-OCR 文字识别模型（CTC），且必须配上它训练时用的字符字典。Paddle、MNN、PyTorch 格式和 manga-ocr 这类编码器-解码器模型都不能用。
- 「输入高度」：PP-OCRv3 及之后的模型为 48，更早的为 32。
- 下载后会试运行一次模型；无法运行、不是识别模型、字典行数与模型类别数对不上时，文件会被删除并显示原因。
- 自定义源语言需要在「源语言」中手动选择，「自动检测」只在内置语言之间判断。
- 语言列表随备份在设备间同步，模型文件不同步，每台设备需各自下载。

**自定义文字检测模型**

同一页面的「文字检测模型」可以换成自己的模型，所有语言共用。只支持 ONNX 格式的 PP-OCR 文字检测模型（DBNet），可选已验证的 PP-OCRv5 mobile（约 4.8 MB）或 PP-OCRv6 small（约 9.9 MB）。检测模型越大，越能找到小字和艺术字，但每页都会变慢。下载完成前仍使用内置检测模型。

### 自定义翻译脚本

用于接入请求格式、鉴权方式或响应结构不兼容 OpenAI 的翻译服务，也可连接自己的翻译网关。使用 OpenAI 兼容服务时，直接选择「AI 模型」即可，无需编写脚本。脚本只替换文本翻译步骤，仍需下载文字检测与识别模型。

1. 设置 → AI 翻译 → 「LLM 服务商」→ 新增或编辑服务商。
2. 服务类型选择「自定义翻译脚本」。按脚本需要填写 API 地址、API Key 和模型名；这三个字段作为参数传给脚本，不需要的可以留空。
3. 点击「编辑翻译脚本」，编写 `translate(input)` 函数。可先使用下面的离线示例，再点击「测试脚本」。
4. 点击编辑器右上角「保存」，返回服务商窗口后还要点击「保存」，最后在服务商列表中选中它。仅保存编辑器或测试成功都不会自动完成服务商的保存与切换。

函数收到一个对象，包含以下字段：

| 字段 | 含义 |
| --- | --- |
| `texts` | 本次待翻译的字符串数组，可能包含一页或多页文字 |
| `sourceLang` | 源语言代码，如 `en`、`ja`、`zh`；`auto` 表示应用尚未确定源语言，脚本或服务端需自动识别，或将它映射为该 API 支持的自动检测参数 |
| `targetLang` | 目标语言代码，如 `zh`、`zh-TW`、`en`，或自定义目标语言的代码；按服务商要求转换语言代码 |
| `glossary` | 该漫画已有的术语表，格式为 `{原文: 译文}`；脚本需自行在请求中传递或应用，才能保持译名一致 |
| `provider` | 服务商窗口中的 `{url, key, model}`，均为字符串；应用不会替脚本补全 URL 路径或添加鉴权头 |

返回 `{texts: [...], glossary: {...}}`，其中 `glossary` 可省略；也可直接返回字符串数组。译文必须与输入数量相同、顺序一致，每项都必须是字符串。返回的术语表键和值也必须是字符串，用于补充该漫画后续翻译的术语；过长、像整句、网址或数字的条目会被过滤。返回 JavaScript 对象或数组即可，不要再用 `JSON.stringify` 包装返回值。

**离线冒烟示例**：不联网，只给每条原文加上 `[test]` 前缀，验证脚本能运行、结果格式正确，**不执行实际翻译**。测试应显示 `[test] Hello`；请在正式阅读前替换它。

```javascript
function translate({texts}) {
    // Smoke test only; no translation or network request.
    return {texts: texts.map(text => '[test] ' + text)};
}
```

**HTTP 接入示例**：以下假设你的服务接收 `texts`、`source`、`target`、`model` 和 `glossary`，返回 `{"translations":[{"text":"你好"}],"glossary":{}}`。这是请求与响应映射的示范，不是通用即用接口；必须根据服务文档修改字段、鉴权方式和语言代码，并将完整接口地址填入服务商的 API 地址。

```javascript
async function translate({texts, sourceLang, targetLang, glossary, provider}) {
    const headers = {'Content-Type': 'application/json'};
    if (provider.key) headers.Authorization = 'Bearer ' + provider.key;
    const response = await Network.sendRequest(
        'POST', provider.url, headers,
        JSON.stringify({
            texts, source: sourceLang, target: targetLang,
            model: provider.model, glossary
        })
    );
    if (response.status < 200 || response.status >= 300) {
        throw new Error('HTTP ' + response.status);
    }
    const data = JSON.parse(response.body);
    // Adapt this mapping to your API's response.
    return {
        texts: data.translations.map(item => item.text),
        glossary: data.glossary || {}
    };
}
```

`Network.sendRequest(method, url, headers, data)` 发送 HTTP(S) 请求，返回 `response.status`（状态码）、`response.headers`（响应头，每项值为数组）和 `response.body`（响应文本）。JSON 请求体需自行序列化，JSON 响应需自行解析。非成功 HTTP 状态不会自动作为脚本错误抛出，须像示例一样检查。可使用标准 JavaScript、`JSON`、数组处理和 `async` / `await`；应用接口仅开放网络请求，其他 Venera API（如文件、存储和界面操作）不可用。

- 「测试脚本」运行编辑器内当前代码，输入固定为 `texts: ['Hello']`、`sourceLang: 'en'`、`targetLang: 'zh'`、空术语表，并使用打开编辑器时的服务商参数。含网络请求的脚本会实际访问接口，可能消耗额度；修改服务商参数后需重新打开编辑器测试。
- 测试最多等待 30 秒，正常翻译调用最多等待 3 分钟；单次同步 JavaScript 执行约有 1 秒限制。避免死循环和长时间同步运算，使用异步网络请求。
- 未定义 `translate`、语法错误、无效 URL、请求失败、超时、译文数量或类型不符、术语表格式错误都会导致失败。先用离线示例确认编辑器能运行，再检查接口状态、鉴权、语言代码与响应字段；阅读时可点击失败图标查看原因并重试。
- 脚本能够读取本次文本、术语表及服务商密钥，并向脚本指定的 HTTP(S) 地址发送请求。只运行自己理解或信任的脚本，确认请求地址；将密钥填在服务商字段并通过 `provider.key` 使用，不要硬编码在脚本、示例或错误信息里。
- 脚本代码仅保存在本机，不随同步传到其他设备；在另一台设备上使用该服务商前，需要另行添加并测试脚本。

<!--anchor:translation-enable-->
### 启用

翻译按漫画单独启用，无全局开关，因其消耗用户自有额度。两处入口：

- 漫画详情页 → 右上角更多菜单 → 「启用 AI 翻译」。
- 阅读器 → 设置 → AI 翻译 → 「阅读时翻译页面」。

启用后逐页翻译，完成前显示原图。如需提前翻译，详情页会出现「预翻译」按钮，选择章节后在后台执行，进度见任务页。

<!--anchor:translation-reading-->
### 阅读时的操作

- 顶栏图片图标：在译图与原图间切换，用于对照，不影响翻译设置。
- 顶栏进度圈：当前页正在翻译。
- 顶栏红色警告图标：当前页失败，点击查看原因并重试。

<!--anchor:translation-adjust-->
### 调整翻译结果

长按详情页的「预翻译」按钮，可打开：

- **术语表**：查看并修正该漫画已学习的人名与专有名词译法，后续翻译沿用修正结果。
- **重新翻译**：清除该漫画的全部译文与术语表后重新翻译。

其他方式：

- 仅重做部分章节：在章节选择界面勾选后使用「重新翻译所选」。
- 译文遮盖效果不佳：调整「文字消除」。「智能消除」（默认）尽量还原气泡底色与网点；「色块遮盖」直接覆盖纯色块，速度更快但边界生硬。

<!--anchor:translation-performance-->
### 性能与用量

译文文字结果会保存，同一页通常只做一次 OCR 和 LLM 请求，重复阅读不再产生费用；切换「智能消除/色块遮盖」只重新绘图，不重复 OCR 或翻译。「清除翻译结果」可释放空间，各漫画已学习的语言与术语表保留。升级到本版本前生成的旧格式结果会自动丢弃，需要重新翻译。

速度不佳或服务商返回限流错误时，可调整：

| 设置项 | 说明 |
| --- | --- |
| 性能档位 | 「省资源」降低内存与发热；「均衡」（推荐）适合大多数设备；「快速」提高并发但更耗电。档位只保存在当前设备，不会用桌面设置覆盖手机 |
| 每次预翻译请求页数 | 单次请求包含的页数。增大可减少请求数，但单次耗时更长，过大易超出模型上下文 |
| 翻译请求并发 | 同时发出的请求数。出现限流时下调 |
| OCR 并行 | 本机识别线程数，0 为自动。移动端会自动限制并发；日文模型在移动端固定单线程。设备发热或卡顿时下调 |
| 图片下载并发 | 同时下载的图片数 |

一般无需调整高级设置；修改任一性能细项后，档位会自动变为「自定义」。译文会按每个文字行的紧框清理原文并限制在自己的区域内，尽量避免擦到人物和背景；复杂背景、超长句或特殊排版仍可能需要重译或手动切换「色块遮盖」。

「翻译提示词」可替换内置提示词。内置版本要求译文口语化、沿用已确定的人名译法、并回报本页新出现的专有名词，这些要求本身占用输入 token；本地部署的小模型如果吃不住，可以改写得更短，代价是译文质量和跨页人名一致性下降。写自定义提示词时需注意：

| 占位符 | 替换为 |
| --- | --- |
| `$target` | 目标语言名称，如「简体中文」；自定义目标语言为添加时填写的名称 |

提示词还需说明两件事，否则功能会失效：一是要求模型只输出 `{"lines":[{"id":0,"text":"译文"}]}` 这样的 JSON 对象，且每个 id 恰好出现一次 —— 应用靠 id 把译文放回对应气泡，解析不出来这一页就算失败；二是如需保持人名一致，要说明沿用 `glossary` 字段给出的译法，并把新出现的专有名词收进 `names` 字段返回。清空输入框保存即恢复内置提示词。该设置随备份在设备间同步。

<!--anchor:translation-limits-->
### 注意事项

- 本功能标记为实验性，识别与翻译均可能出错，长文本与特殊排版尤为明显。
- 日文模型体积较大，因竖排漫画文字目前仅此一种可靠识别方案。
- 推理仅使用 CPU，移动端执行预翻译会明显发热与耗电，建议在充电时进行。

## 漫画缓存目录

用于将在线阅读产生的图片缓存放到空间更充足的磁盘或目录。设置 → 数据与同步 → 数据 → 「漫画缓存目录」→ 「设置」，可选择文件夹，也可输入应用有写入权限的绝对路径，例如 `D:\VeneraCache`。保存时会检查路径和写入权限，并自动创建缺少的文件夹。设置项下方显示当前使用的路径，修改后会补充「重启后使用」路径；点击「使用默认目录」清空输入后保存，即可在下次启动恢复默认位置。

| 位置 | 存放内容 |
| --- | --- |
| `<输入路径>/venera-cache/cache` | 漫画图片缓存 |
| `<输入路径>/venera-cache/cache.db` | 与图片缓存配套的索引数据库 |

输入的是父目录，应用会自动追加 `venera-cache/cache`，不要把这段再填一遍。不要在应用创建的 `venera-cache` 中放其他文件；同名目录已有不相关内容，或缓存子目录为链接时，设置可能被拒绝。路径不可用时，请检查绝对路径、磁盘是否已连接、目录权限及已有文件。

- **重启后生效**：保存设置不会立即切换正在使用的缓存目录。完全退出并重新启动应用后才使用新位置。
- **旧缓存保留，不会迁移**：切换后会在新位置重新积累缓存。需要释放旧缓存空间时，建议在切换并重启前使用「清除缓存」。
- **清理当前实际使用的缓存**：「清除缓存」只清理本次运行正在使用的位置，不会遍历以前设置的目录，也不会清空你输入的父目录。修改路径后尚未重启时，清理的仍是旧位置；启动回退后则清理默认位置。
- **恢复默认**：清空路径并保存，重启应用；自定义目录中的旧缓存仍保留。
- **启动回退**：若自定义路径在启动时不可用，应用提示错误并在本次运行中使用默认缓存目录，已保存的自定义路径不会被清空。修复路径或权限后重启即可重试。
- **仅影响图片缓存**：已下载漫画、翻译识别模型及其他应用数据不会搬迁。下载漫画的存放位置由独立的本地漫画存储路径设置管理。
- **仅本机保存**：缓存路径不随设备同步，需在每台设备上分别设置。

## 合集

将同一作品分开发布的多部漫画合并为一部阅读，适用于分卷、分部、分季的情况。合并后共用一个封面、一份章节列表、一条阅读进度，收藏与追更亦仅一条记录。成员可来自不同来源。

原有漫画保持不变，合集是额外的入口。

<!--anchor:collection-create-->
### 创建

批量创建：

1. 在任意列表中长按一部漫画进入多选，勾选属于同一作品的各部。
2. 工具栏合集图标 → 「加入合集」。
3. 目标选择「新建合集」，填写名称（留空则使用第一部的标题）。
4. 选择章节展示方式后确认。

单部加入：长按漫画 → 「加入合集」，或左右滑动列表行，或在详情页更多菜单中操作。

加入时可选：将新合集收藏至指定文件夹；勾选「取消所选漫画的收藏」，使收藏夹中仅保留合集一条记录。

<!--anchor:collection-layout-->
### 章节展示方式

- **合并章节**：各成员章节合为一条列表。适用于每部本身即为一话或一卷。
- **分部标签**：每部一个标签页，各自管理章节。适用于每部内部仍有多章。

可随时切换，已读进度与已下载章节不受影响。

<!--anchor:collection-edit-->
### 编辑

合集入口位于主页「合集」卡片，无合集时不显示。调整其位置或隐藏：设置 → 外观 → 主页布局。

在合集页菜单选择「编辑」，可修改：

- **合集名称**：留空则使用第一部的标题。
- **封面**：使用第一部的封面、选择本地图片，或使用某成员的封面。成员显示「打开一次即可获取封面」表示其封面尚未缓存，需先打开该漫画一次。
- **章节展示方式**。
- **顺序**：拖动右侧手柄。成员顺序即章节顺序，可用于纠正来源中分部次序错误的情况。
- **成员**：成员右侧菜单可修改其在合集中的显示名称、单独打开该漫画，或从合集移除。

在合集详情页使用「分部标签」时，长按标签（桌面端右键）可直接修改显示名称、调整次序或移除成员，无需进入编辑页。

<!--anchor:collection-limits-->
### 限制

- 合集不可嵌套。
- 删除合集不会删除其中的漫画，仅清除合集本身及其收藏与历史记录。
- 成员标红显示「不可用」表示其来源未安装或本地文件缺失，需移除或恢复来源。
- 合集的更新时间取成员中的最新值。
- 合集配置与自定义封面随备份和同步一并处理。

## 自动翻页

阅读时打开菜单，点击底栏的「自动翻页」按钮开启，再点一次关闭。

- **画廊模式**：按固定间隔翻页，间隔 1–20 秒，默认 5 秒。
- **连续模式**：「自动翻页方式」可选「翻页」或「滚动」。「滚动」为匀速滚动，速度 1–30，默认 15；速度按图片宽度换算，手机、平板与桌面端的阅读节奏一致。

间隔、方式与速度在 设置 → 阅读设置 中修改，也可在阅读器菜单的「设置」中修改；与其他阅读设置一样，可按漫画或按设备单独设置。

运行中打开菜单，底栏上方会多出一行，可直接调整间隔或速度，或点「停止」结束，调整结果会保存到设置。

- **自动暂停**：打开菜单或弹窗、进入其他页面、应用切到后台时暂停，返回后重新计时。
- **手动接管**：滚动方式下，触摸、拖动、滚轮或点击翻页会暂时接管，松手片刻后自动继续滚动。
- **等待加载**：遇到仍在加载的页面会等待加载完成，不会直接跳过；翻页方式下，手动翻页或新章节加载后重新计时。
- **结束**：读到最后或章节加载失败时停止，并给出提示。
- **屏幕常亮**：自动翻页运行期间屏幕保持常亮，仅手机和平板。

只想阅读时屏幕不熄灭、不需要自动翻页时，打开 设置 → 阅读设置 → 「阅读时屏幕常亮」。仅手机和平板，默认关闭，可按漫画或按设备单独设置。

<!--anchor:eink-->
## 墨水屏

设置 → 阅读设置 → 「墨水屏」。这些设置只保存在本机，不随同步，避免同步到手机后每次翻页都闪屏。

**翻页时全屏刷新**：翻页停稳后用纯色短暂铺满屏幕，让墨水屏整屏重绘，清除上一页的残影。仅画廊模式生效。

| 选项 | 说明 |
| --- | --- |
| 刷新颜色 | 白色（默认）、黑色、先黑后白 |
| 刷新间隔（页） | 每翻几页刷新一次，1–10，默认 1 |
| 刷新时长（毫秒） | 每种颜色的停留时间，50–1000，默认 150 |

残影仍未清干净时，可加长刷新时长，或改用「先黑后白」。

**水波纹翻页**：仅在系统为 SmartOS 4 及以上的掌阅设备上显示。画廊模式下点击或按键翻页时，用设备自带的水波纹效果代替滑动动画，方向随阅读方向和屏幕旋转自动调整；手指拖动翻页不受影响。可在「水波纹速度」中选择较慢、标准或较快。轮到全屏刷新的那一页不使用水波纹。

两项功能目前缺少真机反馈。刷新无效或水波纹方向不对时，请反馈设备型号与系统版本。

<!--anchor:gestures-->
## 非显性操作

以下操作无对应按钮。移动端为长按，桌面端多数支持右键。

列表与收藏：

- 长按漫画：打开操作菜单（加入合集、收藏、稍后阅读等）。
- 左右滑动列表行：快捷操作。
- 长按进入多选后可批量处理。
- 长按主页空白处：进入主页板块排序，可拖动或隐藏板块。

漫画详情页：

- 长按封面：保存封面图片。
- 长按「收藏」：跳过选择面板，直接收藏至默认文件夹。
- 长按「预翻译」：打开翻译菜单（预翻译、术语表、重新翻译）。
- 长按标题或标签：复制文字。
- 长按章节：进入章节多选，可批量标记已读、下载或重新翻译。
- 长按分部标签（仅合集）：修改显示名称、调整次序、移除成员。
