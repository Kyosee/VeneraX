# VeneraX 使用说明

只讲「在哪里、怎么点」。找不到某个设置时，打开设置页，用顶部的搜索框搜关键词。

## AI 翻译 {#ai-translation}

把页面里的文字译好，直接画在原图上，画面保留。**找字和认字在你的设备上完成，认出来的文本再发给你自己配置的 AI 服务翻译。** 应用不带任何账号或额度，用的是你自己的。

### 第一次配置

1. 设置 → 阅读 → 展开「AI 翻译（实验性）」。
2. 点「LLM 服务商」→ 添加一个，填 API 地址、API Key、模型。任何兼容 OpenAI 接口的服务都可以。可以添加多个，随时切换。
3. 点「测试翻译」。能返回译文就说明通了；报错就按提示改地址或模型名。
4. 点「翻译模型」→ 下载。必须下的是「文字检测」（约 5 MB）；再按漫画语言下一个识别模型：
   - 日文（竖排漫画）约 460 MB
   - 中文 / 拉丁字母 约 11 MB
   - 英文 约 9 MB
   - 韩文 约 8 MB

模型从 HuggingFace 下载。国内连不上时，把「模型下载来源」切成 hf-mirror.com。

「源语言」保持「自动检测」时，只要装了检测模型加任意一个识别模型就能开始用，程序会自己判断这本是什么语言。

### 开始翻译

翻译是**按每部漫画单独开**的，不是全局开关，因为它花的是你的额度。

- 在漫画详情页点右上角的更多菜单 → 「启用 AI 翻译」。
- 或者进入阅读器 → 设置 → 「阅读时翻译页面」。

开启后翻到哪页就译哪页，译好之前先显示原图。

想提前译好再看：详情页会多出一个「预翻译」按钮，点它选章节，翻译在后台跑，进度在任务页看。

### 阅读时能做什么

- 顶栏的图片图标：切「显示原图 / 显示译图」，用来对照原文，不用去关设置。
- 顶栏转圈：这页正在翻译。
- 顶栏红色感叹号：这页失败了，点一下看原因并重试。

### 译得不满意

- **长按详情页的「预翻译」按钮**，会弹出菜单：
  - 「术语表」：查看和修改这部漫画学到的人名、专有名词译法，改完后面都按你改的来。
  - 「重新翻译」：清掉这部漫画的全部译文和术语表，重新译。
- 只想重做某几章：在选章节的界面里勾上，用「重新翻译所选」。
- 文字被盖得难看：改「文字消除」。「智能消除」（默认）会尽量还原气泡底色和网点；「色块遮盖」是直接盖一块纯色，速度快但生硬。

### 省额度和提速

译过的页面会存下来，同一页只译一次，重看不再花钱。想腾空间就用「清除翻译结果」，每部漫画学到的语言和术语表会保留。

嫌慢或嫌服务商限流报错时，调这几项：

- 「每次预翻译请求页数」：一次发几页给 AI。发得多更省请求数，但单次更慢，太大容易超出模型上下文。
- 「翻译请求并发」：同时发几个请求。被限流就往小调。
- 「OCR 并行」：本机认字用几个线程，0 是自动。手机发烫或卡顿就调小。
- 「图片下载并发」。

### 说明

- 这个功能标着「实验性」：识别和翻译都可能出错，长文本和特殊排版尤其容易。
- 日文模型体积大，是因为竖排漫画文字目前只有这一种可靠的识别方式。
- 纯 CPU 推理，手机上开预翻译会发热耗电，建议插电时跑。

## 合集 {#collections}

把同一个故事分开发布的多本漫画合成一本看：分卷、分部、第一季第二季。合成后只有一个封面、一份章节列表、一条阅读进度，收藏和追更也只有一条。**成员可以来自不同来源，混着放没问题。**

原来的那几本漫画不动，只是多了一个入口。

### 建一个合集

最省事的做法是批量加：

1. 在任意列表里进入多选（长按一本漫画），把这个故事的几本都勾上。
2. 点工具栏的合集图标 →「加入合集」。
3. 目标选「新建合集」，填名字（留空就用第一本的标题）。
4. 选章节展示方式（见下），确认。

单本也能加：长按一本漫画 →「加入合集」；或者在列表里左右滑动那一行；或者在详情页的更多菜单里。

加入时还有两个选项：把新合集收藏到某个文件夹，以及「取消所选漫画的收藏」——收藏夹里只留合集这一条，不再重复。

### 两种章节展示方式

- **合并章节**：所有成员的章节接成一条列表。适合每本本身就是一话、一卷的情况。
- **分部标签**：每本一个标签页，各自管自己的章节。适合每本内部还有很多章。

选错了随时能改，已读进度和已下载的章节不会因为切换而失效。

### 调整合集

合集入口在主页的「合集」卡片（没有合集时不显示）。想调它在主页的位置或藏起来：设置 → 外观 → 主页布局。

在合集页点菜单 →「编辑」，可以改：

- **合集名称**：留空就用第一本的标题。
- **封面**：用第一本的封面、选一张本地图片，或者用某个成员的封面。成员封面显示为「打开一次即可获取封面」时，说明还没缓存过它的封面，先点进那本漫画看一眼。
- **章节展示方式**。
- **顺序**：拖右侧的手柄。**成员顺序就是章节顺序**，来源把第三部排在第一部前面时，在这里拖回来。
- **成员**：点成员右侧菜单 →「显示名称」改它在合集里叫什么、「详情」单独打开它、「从合集移除」。

已经在看合集详情页、用的是「分部标签」时，**长按（电脑上右键）标签本身**就能直接改显示名称、左移右移、移除，不用回编辑页。

### 注意

- 合集不能放进另一个合集里。
- 删除合集不会删掉里面的漫画，只清掉合集本身和它的收藏、历史记录。
- 成员漫画标红显示「不可用」，说明它的来源没装或本地文件没了，移除或补回来即可。
- 合集的更新时间取成员里最新的那个。
- 合集配置和自定义封面都会跟着备份与同步走。

## 隐藏操作速查 {#gestures}

这些操作没有明显的按钮，但很好用。手机上是长按，电脑上多数也支持右键。

阅读列表和收藏：

- 长按一本漫画：打开操作菜单（加入合集、收藏、稍后阅读等）。
- 列表里左右滑动一行：快捷操作。
- 长按后进入多选，再批量处理。
- 长按主页空白处：进入主页板块排序，可以拖动或隐藏各个板块。

漫画详情页：

- 长按封面：保存封面图片。
- 长按「收藏」按钮：跳过选择面板，直接收进默认收藏夹。
- 长按「预翻译」按钮：打开翻译菜单（预翻译 / 术语表 / 重新翻译）。
- 长按标题或标签：复制文字。
- 长按章节格子：进入章节多选，可批量标记已读、下载、重新翻译。
- 长按分部标签（仅合集）：改显示名称、调顺序、移除成员。
