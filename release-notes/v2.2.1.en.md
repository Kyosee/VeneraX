## What's Changed

### Added
- Comic collections: combine comics released as separate volumes or parts into one, across sources
- Collection chapters can be merged into a single list or shown as one tab per comic, with renaming and reordering
- A collection tracks its own reading progress, downloads and follow-updates; member comics keep theirs
- Collection cover can be taken from a member comic, picked from a local image, or reset to default
- Add to a collection from the list long-press menu, swipe, multi-select, detail page menu, or the favorites multi-select menu
- Blocked tags, kept separate from blocked keywords, with a shortcut to block a comic's tags from its detail page
- Detail pages matching a blocked tag now show a notice, with the option to view anyway
- WebDAV comic library supports multiple addresses and accounts: add, edit, delete, reorder, and switch with one tap
- Each WebDAV library keeps its own reading progress, favorites and image cache; you can pick the target library when uploading local comics
- AI translation can now erase the original lettering and rebuild the bubble background instead of covering it with a solid block
- Cancel a single chapter mid pre-translation without stopping the rest
- Delete or re-translate one chapter's translation, or delete every translation for a comic
- Pre-translate chapter picker shows tabs per group for grouped comics

### Changed
- Source language, target language and text-erase mode for AI translation are now saved per comic
- Network request logs only record failures by default; full logging can be enabled on the logs page when troubleshooting
- Faster pre-translation for long chapters

### Fixed
- Continuous battery drain and heating while reading
- Pre-translation stuck with no progress for a long time
- Crash on some devices after enabling AI translation
- Translated text too large and overflowing the bubble
- Garbled text being drawn over regions where OCR found nothing; the original image is now kept
- Switching text-erase mode still showing the old result until restart
- Drag positions being wrong after reversing the order on the favorites sorting page
- Bottom row of buttons in popup pages sitting under the system navigation bar
