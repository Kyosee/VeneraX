## What's Changed

### Added
- Image translation can now translate Traditional Chinese comics, including vertical text; choose Traditional Chinese as the source language or let auto-detect pick it.
- Added a new Chinese text recognition model that reads both Traditional and Simplified Chinese; once downloaded it replaces the old one.
- You can now add your own source languages and replace the text detector with your own models; their size is shown before download and they are checked after it.
- Added Vietnamese as a translation target language.
- You can now add translation target languages that are not in the built-in list, under Custom languages.
- Image enhancement settings now show a live before/after preview; drag the divider to compare, and when opened from the reader it previews the current page.
- Each local favorites folder can now keep its own sort order; "Apply to All Folders" sets the default for every folder.

### Changed
- No other feature changes in this release.

### Fixed
- Fixed Traditional Chinese pages coming back untranslated or with wrong characters; pages that failed before can be fixed with "Re-translate".
- Fixed the download button disappearing for comics with only some chapters downloaded.
- Fixed the comic description appearing twice at the top of the details page.
- Fixed dragging a zoomed-in image to the right on iOS sliding the whole reader page away.

### Removed
- No features were removed in this release.
