## What's Changed

### Added
- AI translation now lets you configure multiple LLM providers and switch between them
- Migrate local comics to your WebDAV library, either the whole library or one comic at a time
- Migration to WebDAV keeps grouped chapters (volumes / chapters / extras tabs)
- Detail page three-dot menu now has an AI translation switch with pre-translate
- Filter favorites by local download status (downloaded / not downloaded)
- Pre-translate failed pages can now be retried automatically or manually
- Confirmation prompt before pre-translating a comic that has no chapters
- Tap a background task notification to jump straight to the matching page
- New settings for OCR / image / translation concurrency

### Changed
- Faster pre-translation for long chapters
- Migration dialog now keeps the original chapter titles by default, with a clearer explanation

### Fixed
- Prev / next chapter buttons at the bottom not working in seamless continuous reading
- Comic images sometimes failing to load after a signed URL refresh
- One failing page group no longer drags down pre-translation for the whole chapter
- Same-name comic folders overwriting each other when resuming a migration
- Detail page crashing for WebDAV library titles that contain a "%" character
