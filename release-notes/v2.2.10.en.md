## What's Changed

### Added
- Comic details now lets you hide duplicate chapters for each comic, keeping chapter, download, and pre-translation lists consistent
- Desktop now offers an option to enter fullscreen automatically when reading starts
- Added an option to remove a comic from Read Later automatically when reading starts

### Changed
- Continuous reading now lets you adjust image width from 40% to 150% of screen height
- Reorganized Settings and moved Appearance options into App
- `comic.onThumbnailLoad` now matches `comic.onImageLoad`: configuration functions may be async, Promise results from `onResponse` are awaited, response types are validated, and `comicId` is passed as the second argument

### Fixed
- Fixed mouse wheel and touchpad scrolling not working over blank side margins when image width was limited in continuous reading
- Fixed per-comic image width limits not being applied correctly in continuous reading
- Fixed Settings sometimes crashing when a saved setting value was empty
