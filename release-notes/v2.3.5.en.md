## What's Changed

### Added
- Import PDF files as local comics.
- Reorder comic chapters in batches.
- Choose a custom comic cache directory, with a folder picker and an option to restore the default location.
- Connect translation services through custom scripts, with an example and a test panel.
- Search tasks and combine task type and status filters.
- See whether reading settings come from global, device or per-comic preferences, and restore inherited values individually.

### Changed
- Settings categories now have short descriptions, AI Translation has its own entry, and wide-screen settings open with content already selected.
- Settings search opens and highlights the relevant option, with an explanation when an option is unavailable in the current mode.
- Clearer task cards and action buttons, especially on phones and with larger text.
- Empty libraries, empty categories and searches with no results now provide clearer guidance and actions.
- Setting sliders preview changes immediately and save on release or when leaving the page, reducing interruptions during adjustment.
- Smoother startup handling with large caches and more efficient display of long task lists.

### Fixed
- Fixed missing pages or incomplete endings when exporting large EPUB files.
- Fixed favorites search missing matches with mixed Simplified and Traditional Chinese or pasted keywords.
- Fixed long favorite-folder names crowding the favorites panel.
- Fixed some reading options not following device or per-comic preferences.
- Fixed lengthy retries for missing local covers and reads continuing after loading was canceled.
- Fixed startup cleanup potentially removing new cache files while they were being written.

### Removed
- No features were removed in this release.
