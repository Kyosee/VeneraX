## 更新内容

### 新增
- 新增鸿蒙（HarmonyOS）版本，提供手机用 ARM64 和模拟器用 x64 两个安装包；安装包未签名，需要自行签名后安装（#296）。
- 新增最近阅读、追更、有更新、本地漫画四种桌面小组件，支持 Android、HarmonyOS（服务卡片）、iOS 和 macOS；Apple 平台能否使用取决于签名与侧载方式（#338）。
- 长按应用图标可快速打开收藏、追更、历史和搜索，支持 Android、iOS 和 HarmonyOS；Android 和 iOS 更新后需先打开一次应用才会出现（#346）。
- 新增可选的自适应阅读模式，根据漫画图片识别条漫与页漫，自动选择合适的阅读方式（#333）。
- 新增首次使用引导，帮助新用户完成语言、权限、备份恢复与 WebDAV 设置；已有用户不会进入引导。
- 新增「手动删除单条历史记录时清除阅读进度」选项，开启后删除单条历史会一并清除阅读进度，阅读时长统计保留（#341）。

### 变更
- 阅读统计改版，支持近期、按月、全部及自定义日期范围，新增阅读日历与趋势，作品可查看累计阅读时长（#332、#342）。
- 抽卡支持「单抽」与「三选一」两种方式，同一轮不会出现重复的漫画。
- 本地漫画可设置点击后查看详情或直接阅读、按文件大小排序，删除时可分别选择是否删除漫画文件、收藏和历史记录（#321）。
- 收藏弹窗支持连续添加或移除多个收藏夹，操作后不再自动关闭（#345）。
- 「自动语言筛选」开关改为在搜索语言过滤中自行选择适用的漫画源，避免影响不支持该筛选的来源。
- 导入漫画时显示当前步骤、进度条和正在处理的漫画名称；中途失败时，已复制完成的漫画仍会加入书库（#347）。
- 下载遇到个别失效页面时会继续下载其余内容，之后可补下缺页或保留已下载内容。
- 从下一章第一页往前翻时，会先回到上一章的评论页，再往前才是上一章最后一页（#343）。
- 章节评论页支持点击翻页区域翻页。
- 更新弹窗重新设计，更新日志与下载进度显示更清晰。
- Windows 更新窗口改用与应用一致的配色，并显示安装进度。
- 日志页支持搜索、按级别与标签筛选、导出，并保留上次运行的日志，方便排查问题。
- 封面缓存保留更久（最后一次查看后 90 天），在漫画详情页下拉刷新可更新封面（#332）。
- 图片翻译模型下载在服务器支持时可断点续传，失败后可重试（#335）。
- 优化设置页布局：侧栏搜索框始终可见，宽屏下分组单列显示，历史记录设置移入「浏览与过滤」。
- 桌面端 Esc 和鼠标返回键改为逐层返回，不再直接退回首页。
- 优化大型书库的浏览性能，减少进入列表和切换页面时的卡顿。
- 精简备份中的不必要内容，在保留个人数据的同时减少备份占用。
- 更新用户协议与免责声明。

### 修复
- 修复连续阅读时点击上一话，标题变了但内容仍是原章节的问题（#340）。
- 修复从右往左连续阅读时，翻页与已保存的阅读进度不同步的问题。
- 修复开启双页拆分或横屏双图时，快速翻页出现图片重复、错位或先闪出整张图的问题（#337）。
- 修复从右往左阅读时，快速连续右划或在翻页动画中右划会误触返回的问题（#344）。
- 修复下载请求或缓存异常导致任务卡住的问题。
- 修复更新下载后本地漫画章节重复的问题。
- 修复漫画归档与 CBZ 导出再导入后章节或页面不完整、内容重复的问题。
- 修复 Android 使用外置目录时漫画归档导入导出路径异常的问题。
- 修复 PDF 导出失败或取消后任务状态不正确的问题。
- 修复收藏标签含逗号或引号时被拆分或改写的问题。
- 修复已清除的阅读进度被刷新等操作重新写回的问题。
- 修复在其他设备读过的本地漫画，历史记录没有封面且无法打开的问题（#348）。
- 修复其他设备已读的追更更新又被重新标记为有更新的问题（#336）。
- 修复保存 WebDAV 设置时重复执行初次同步的问题（#335）。
- 修复设备认证不可用时应用锁未保持锁定的问题。
- 修复桌面端按 Esc 可关闭应用锁界面的问题。
- 修复手机端简洁模式下标题和封面被挤压裁切的问题，标题旁的操作按钮已移除（#331）。
