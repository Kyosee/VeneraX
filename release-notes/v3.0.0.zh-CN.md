## 更新内容

### 新增
- 新增 HarmonyOS 鸿蒙版本。
- 新增最近阅读、追更、有更新、本地漫画四类桌面小组件与服务卡片，支持 Android、HarmonyOS、iOS 和 macOS；Apple 平台的可用性取决于实际签名与侧载方式。
- Android、iOS 和 HarmonyOS 新增应用图标快捷入口，可快速打开收藏、追更、历史和搜索。
- 新增可选的自适应阅读模式，根据漫画图片识别条漫与分页漫画，自动选择适合的阅读方式。
- 新增首次使用引导，帮助新用户完成语言、权限、备份恢复与 WebDAV 设置，已有用户不会重新进入引导。
- 删除单条阅读历史时，可同时清除该漫画的阅读进度，并保留阅读时长统计。

### 调整与优化
- 全新的设置界面。
- 阅读统计全面改版，支持近期、按月、全部及自定义日期范围，并提供阅读日历与趋势展示。
- 抽卡支持「单抽」与「三选一」两种方式，同轮候选漫画不重复。
- 本地漫画支持设置点击后的默认操作、按体积排序，并可分别选择删除漫画文件、收藏记录和阅读历史。
- 优化单本漫画的收藏弹窗，调整收藏文件夹后可继续操作，方便连续整理。
- 搜索语言过滤支持自行选择适用的漫画源，避免影响不支持该筛选方式的来源。
- 下载遇到个别失效页面时可继续下载其余内容，并支持补下缺页或保留已下载内容。
- 章节末尾的评论页支持按阅读点击区域翻页；返回上一章时可正常经过评论页和最后一页。
- 更新弹窗重新设计，更新日志与下载状态展示更清晰。
- Windows 更新窗口采用与应用一致的配色，并显示安装进度。
- 日志支持搜索、按级别与标签筛选、导出，并保留上次运行日志，方便排查问题。
- 优化封面缓存与刷新，减少重复加载，方便更新过期封面。
- 图片翻译模型下载支持在服务器允许时断点续传，并可重试失败的下载。
- 优化设置项布局与搜索结果展示。
- 优化 Esc 和鼠标返回键的行为，支持逐层返回。
- 优化大型书库的浏览性能，减少进入列表和切换页面时的卡顿。
- 精简备份中的不必要内容，在保留个人数据的同时减少备份占用。
- 更新用户协议与免责声明。

### 修复
- 修复连续阅读切换章节时的图片显示和反向阅读定位问题。
- 修复宽页、双页及快速翻页时的图片加载异常。
- 修复阅读时误触返回的问题。
- 修复下载请求或缓存异常导致任务卡住的问题。
- 修复归档与 CBZ 导入时章节或页面不完整、内容重复的问题。
- 修复 Android 使用外置目录时归档路径处理异常的问题。
- 修复 PDF 导出失败或取消后任务状态不正确的问题。
- 修复包含特殊字符的收藏标签处理异常的问题。
- 修复已清除的阅读进度被刷新操作重新写回的问题。
- 修复 WebDAV 重复执行初次同步的问题。
- 修复设备认证不可用时应用锁未保持锁定的问题。
- 修复紧凑漫画卡片中操作按钮挤压标题的问题。
