## What's Changed

### Added
- Customize the chapter order of each comic
- Create a new folder directly from the favorites panel
- Choose exactly which settings stay on this device in WebDAV sync, now covering all settings including AI translation, network, downloads, home layout and search history

### Changed
- Easier-to-use collection picker
- Skip-sync options moved to their own page under WebDAV sync, with Select All

### Fixed
- Fix language tags disappearing or being hard to see on comic cards
- Fix saved translations showing on the wrong page in some cases
- Fix WebDAV upload failing when the local library is in a folder you picked yourself
- Fix downloads of collection comics failing in some cases
- Fix some images failing to display without a proper error
