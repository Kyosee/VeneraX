## What's Changed

### Added
- Added a HarmonyOS version.
- Added Recent reading, Following, New updates and Local comics widgets and service cards for Android, HarmonyOS, iOS and macOS; availability on Apple platforms depends on the actual signing and sideloading method.
- Added app icon shortcuts on Android, iOS and HarmonyOS for quickly opening Favorites, Following, History and Search.
- Added an optional adaptive reading mode that identifies vertical-scroll and paginated comics from their images and automatically selects a suitable reading layout.
- Added a first-use guide for language, permissions, backup restore and WebDAV setup; existing users will not go through the guide again.
- Deleting an individual history entry can now also clear that comic's reading progress while preserving reading time statistics.

### Changed
- Introduced a redesigned settings interface.
- Redesigned reading statistics with recent, monthly, all-time and custom date ranges, plus a reading calendar and trends.
- Random picks now offer Single draw and Choose one of three modes, with no duplicate candidates in the same round.
- Local comics now support a configurable default tap action, sorting by size, and separate options for deleting comic files, favorite records and reading history.
- Improved the favorites dialog for an individual comic so you can keep organizing folders after making a change.
- Search language filtering now lets you choose which comic sources it applies to, avoiding interference with sources that do not support this type of filter.
- Downloads can continue past individual unavailable pages, with options to retry missing pages or keep the content already downloaded.
- End-of-chapter comments now support the reader's tap-to-turn areas; navigating back to the previous chapter correctly passes through its comments and last page.
- Redesigned the update dialog for clearer release notes and download status.
- The Windows update window now uses colors consistent with the app and shows installation progress.
- Logs now support search, filtering by level and tag, export, and keeping logs from the previous run to help troubleshoot problems.
- Improved cover caching and refresh to reduce repeated loading and make outdated covers easier to update.
- Translation model downloads now support resuming interrupted downloads when the server allows it, as well as retrying failed downloads.
- Improved settings layouts and search result presentation.
- Improved Esc and mouse Back button behavior so navigation goes back one level at a time.
- Improved browsing performance in large libraries to reduce delays when opening lists and switching pages.
- Reduced backup size by removing unnecessary content while preserving personal data.
- Updated the user agreement and disclaimer.

### Fixed
- Fixed image display and reverse-reading position issues when continuous reading switches chapters.
- Fixed image loading issues with wide pages, double-page layouts and rapid page turns.
- Fixed accidental Back actions while reading.
- Fixed downloads getting stuck after request or cache errors.
- Fixed incomplete chapters or pages and duplicate content when importing archives and CBZ files.
- Fixed archive path handling when using external directories on Android.
- Fixed incorrect task states after a PDF export failed or was canceled.
- Fixed favorites tag handling for special characters.
- Fixed cleared reading progress being written back by a refresh.
- Fixed WebDAV repeating its initial sync.
- Fixed the app lock failing to remain locked when device authentication is unavailable.
- Fixed action buttons squeezing titles in compact comic cards.

### Removed
- No features were removed in this release.
