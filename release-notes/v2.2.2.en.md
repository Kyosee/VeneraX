## What's Changed

### Added
- A built-in guide covering AI translation, collections and hidden gestures, from Settings → About → Guide
- Comic source list can be reordered by long-pressing and dragging, or sorted by name in one tap; the order is kept when syncing to another device
- Pre-translation task cards now show the live stage (downloading images, loading the recognition model, recognizing text, translating, rendering), and expand to show which chapter is running
- Translation tasks have a "View details" button that opens the matching comic
- A performance mode for AI translation with Save resources / Balanced / Fast presets, with the old per-item sliders moved under Advanced settings
- Category and ranking pages now support multi-select and swipe-to-favorite, same as search results
- Multi-select bar can remove the selected comics from every favorites folder at once
- Reading history multi-select can add several entries to the same collection
- Swipe left on a comic for Add to collection and Add to favorites; a long swipe favorites it immediately, and a long right swipe on a favorited comic un-favorites it
- WebDAV library browser can filter the current folder by name
- Appearance setting to turn off the predictive back animation, for systems that force the back gesture without a matching animation
- New Data & Sync settings section, with backup, sync and storage options moved out of the App section

### Changed
- Chapter lists of comics you have opened before are cached and shown instantly, then refreshed in the background with an indicator next to the "Chapters" title
- Search fields and list scrollbars now look the same across the app
- Multi-select actions (add to favorites, add to collection, remove from favorites) moved into the three-dot menu
- Reading settings regrouped so related options sit together
- Adding or editing an LLM provider is back to a flat form (name, API URL, API key, model), without service-type templates

### Fixed
- Pre-translation page count and the chapter progress on the detail page no longer stall for a long time or jump backwards
- Cancelled chapters no longer show a retry button that does nothing
- Pre-translation freezing the whole app while rendering text, and words on one line being split apart
- Comic import returning 0 books for archives with chapter subfolders, uppercase extensions, or several comics in one archive; page order now follows natural numbering
- Chapter list refreshing in the background while you are selecting items
- Custom collection covers not showing up after restoring a backup on another device
- Details and preview taps doing nothing on the collection edit page
- Scrollbar still capturing touches after fading out, fighting the page's own edge gesture
