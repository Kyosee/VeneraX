## What's Changed

### Added
- New Translation Library page that lists comics by translated / not translated
- Opening a comic from the library shows its chapters split into translated and pending
- Clear every translation result of a comic in one action from the library
- Translation Library can be added as a home page section for quick access
- Reading Statistics can now be sorted by last read, reading time, or name
- Import help is now an in-app document instead of an external web page

### Changed
- Home, the main pane and Reading Statistics now fill a wide window instead of keeping a fixed width with empty margins
- The bottom navigation bar now shows icons only
- Refined the look of the update notice on the home page
- The disclaimer now covers derivative work and redistribution

### Fixed
- Fixed the import help title showing untranslated text in some languages

### Removed
- Removed a help entry that pointed to content no longer available
