## What's Changed

### Added
- AI translation now offers a "Google Translate (no key)" service type — no account, address or API key to fill in, just save it and start translating
- The no-key service does not support the glossary, and the endpoint it uses is unofficial, so it may be rate-limited or stop working at any time; stay on an AI model if you need reliability

### Fixed
- Fixed pages translated before an update coming back as untranslated and needing a full re-translation
- Fixed pre-translation progress freezing as soon as one page failed to translate
- Fixed the pre-translation button disappearing on a second device for a comic where translation was enabled; the button now always shows, tells you what is missing and jumps straight to the model download or service settings
- Fixed a backup or sync run failing entirely because a single file was missing, leaving the device unable to upload from then on
- Fixed the text-removal setting still describing an option that no longer exists
