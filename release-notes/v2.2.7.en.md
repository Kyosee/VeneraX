## What's Changed

### Added
- Reading statistics can now be opened directly from the Home page

### Changed
- Refined the Home, Explore, Categories, Follow Updates, and Favorites layouts for more consistent alignment, spacing, and visual hierarchy
- Main navigation and menus now use clearer labels and larger, more consistent tap targets

### Fixed
- Fixed WebDAV backups failing with HTTP 404 on some services such as Nutstore
- Fixed backups sometimes omitting the latest data-sync settings
- Fixed duplicate tags appearing for local comics in list view
- Fixed Follow Updates sometimes retaining an outdated layout after initial setup until the app state changed
- Fixed additional source libraries sometimes being treated as duplicates and refusing to add
