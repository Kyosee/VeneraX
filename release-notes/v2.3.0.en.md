## What's Changed

### Added
- Page jump dialog now shows maximum page count and automatically clamps input to valid range
- Page indicator now appears in navigation bar on all screen sizes
- Manual page jump feature added to reader
- Collection tabs can now be renamed when adding comics to a collection

### Fixed
- Gallery mode settings now display correctly based on the active reader mode
- Page slider in continuous mode now accurately lands on the selected page
- Page slider can now reach both the first and last pages properly
- Image decoding no longer continues during mid-scroll in continuous chapter mode
- Plugin repository synchronization now works correctly
- Dismissible dialogs and duplicate chapters in reader have been fixed
- Full plugin descriptions are now visible in the available plugin list
- Continuous chapter separator now uses correct viewport size
- Continuous mode viewport properly updates when screen orientation changes
