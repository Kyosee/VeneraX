## What's Changed

### Added
- Follow Updates can now follow several favorite folders at once, or every folder including ones you add later
- New Follow Updates settings: how often a comic is re-checked, whether to check right after the app starts, and a daily time before which automatic checks wait
- The Follow Updates page now shows a status strip with the followed scope, comic and update counts, and the time of the last check
- Comic details now show a Reading sources section, so you can see which other sources carry the same comic and link or unlink them
- The source selector on the Explore and Categories pages now has a search box for finding a source by name

### Changed
- Opening the Follow Updates page and refreshing it are noticeably faster on a large library

### Fixed
- Source lists and scripts on a private host can now be saved and updated: addresses carrying `user:password@host` credentials, a host without a dot such as `localhost`, and IPv6 addresses are all accepted
- Fixed installing a source script whose file name carries a query, which previously failed to install
- Fixed the Follow Updates page not opening on a device where no folder is followed yet
